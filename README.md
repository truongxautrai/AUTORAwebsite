# AUTORA — Showroom xe cao cấp

Website showroom ô tô được xây dựng với React và Vite, giao diện tiếng Việt và tương thích với thiết bị di động.

## Chạy dự án

```bash
npm install
npm run dev
```

Mở địa chỉ local mà Vite hiển thị trong terminal. Tạo bản production bằng `npm run build`; xem thử bản build bằng `npm run preview`.

## Tính năng

- Tìm kiếm xe theo tên hoặc hãng; lọc theo dòng xe và mức giá.
- Danh sách xe có thông tin giá, năm sản xuất, số km và nhiên liệu.
- Lưu xe yêu thích trong phiên sử dụng.
- Mở form tư vấn hoặc đặt lịch xem xe, có kiểm tra thông tin cơ bản.
- Giao diện responsive cho desktop và mobile.

Ảnh xe và font chữ được tải từ Unsplash và Google Fonts.
